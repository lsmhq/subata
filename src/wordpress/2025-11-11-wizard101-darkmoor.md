🛠️ Wizard101 汉化补丁修复公告

各位小沃尔们好！ 由于官方在 Darkmoor 版本更新后，将游戏语言从 **`English`** 改为 **`en-US`**， **导致所有旧版汉化补丁与字体包暂时失效（游戏将恢复为纯英文界面）**。

* * *

### 🔧 修复方式一：使用 Subata 自动修复（推荐）

**第一步：更新 Subata 到最新版本（v2.4.2）**

> 旧版 Subata 无法识别新的语言目录，请务必更新！

**第二步：下载并应用最新汉化补丁**

- 打开 Subata
- 进入顶部的【补丁】选项卡
- 选择你需要的汉化版本
- 点击【下载】并【应用】

若补丁未立即生效，可尝试：

- 重复应用几次不同版本；
- 在不同汉化版本间切换再尝试。

⚠️ 注意： 如果未安装 **最新版本的 Subata** ， 则 **Subata 的补丁管理功能将无法正常工作**。

* * *

### 🧩 修复方式二：手动修改（适用于未安装 Subata 的玩家）

1. **定位游戏根目录：**
    - **Steam 版：** 在 Steam 中右键游戏 → 管理 → 浏览本地文件
    - **非 Steam 版：** 右键桌面快捷方式 → 打开文件所在位置
2. **进入目录：**
    
    ```
    Data/GameData
    ```
    
3. **找到并重命名文件：** 将
    
    ```
    Locale_English-Root.wad
    ```
    
    重命名为
    
    ```
    Locale_en-US-Root.wad
    ```
    
4. **如果文件缺失：** 你可以手动下载对应版本的
    
    ```
    Locale_en-US-Root.wad
    ```
    
    并放入同一文件夹中。

* * *
